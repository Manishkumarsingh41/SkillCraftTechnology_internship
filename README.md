# SkillCraft Technology - Data Science Internship Projects

This repository contains data science projects completed during an internship at SkillCraft Technology. The projects demonstrate various data analysis, visualization, and machine learning techniques applied to real-world datasets.

## 📊 Projects Overview

### 1. Student Performance Analysis (SCT_DATA_SCIENCE_01.ipynb)
**Dataset:** StudentsPerformance.csv

**Description:** Analysis of student performance data to understand factors affecting academic achievement. The project explores relationships between demographic factors and test scores in math, reading, and writing.

**Key Features:**
- Exploratory Data Analysis (EDA)
- Statistical visualization of performance metrics
- Correlation analysis between variables
- Comparison across different demographic groups

**Techniques Used:**
- Data grouping and aggregation
- Multiple visualization types (histograms, heatmaps, boxplots, countplots)
- Statistical analysis

**Libraries:** pandas, numpy, matplotlib, seaborn, pywaffle

---

### 2. Road Accident Data Analysis (SCT_DATA_SCIENCE_02.ipynb)
**Dataset:** Road Accident Data.csv

**Description:** Comprehensive analysis of road accident data to identify patterns, trends, and risk factors. The project includes temporal analysis and geographic visualization of accident hotspots.

**Key Features:**
- Time-series analysis of accident patterns
- Geographic visualization using interactive maps
- Missing data handling
- Accident severity analysis

**Techniques Used:**
- Temporal data processing
- Interactive map visualization with Folium
- Data cleaning and preprocessing
- Trend analysis

**Libraries:** pandas, numpy, matplotlib, seaborn, folium, datetime

---

### 3. Titanic Survival Prediction (SCT_DATA_SCIENCE_03.ipynb)
**Dataset:** train.csv (Titanic dataset)

**Description:** Classic machine learning problem predicting passenger survival on the Titanic. The project includes feature engineering, model training, and evaluation.

**Key Features:**
- Comprehensive data preprocessing
- Feature engineering and selection
- Machine learning model implementation
- Model evaluation and validation

**Techniques Used:**
- Missing value imputation
- Categorical encoding
- Feature scaling
- Cross-validation
- Hyperparameter tuning with GridSearchCV

**Machine Learning Models:**
- Random Forest Classifier

**Libraries:** pandas, numpy, matplotlib, seaborn, scikit-learn, mpl_toolkits

---

### 4. Bank Marketing Campaign Analysis (SCT_DATA_SCIENCE_04.ipynb)
**Dataset:** bank.csv

**Description:** Analysis of bank marketing campaign data to predict customer subscription to term deposits. The project focuses on understanding customer behavior and building predictive models.

**Key Features:**
- Customer behavior analysis
- Feature engineering
- Classification model implementation
- Model performance evaluation

**Techniques Used:**
- Data encoding and transformation
- Train-test split for model validation
- Decision tree classification
- Accuracy assessment

**Machine Learning Models:**
- Decision Tree Classifier

**Libraries:** pandas, numpy, matplotlib, scikit-learn

---

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Manishkumarsingh41/SkillCraftTechnology_internship.git
cd SkillCraftTechnology_internship
```

2. Install required packages:
```bash
pip install -r requirements.txt
```

Or install individually:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn folium pywaffle jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open any of the notebook files (.ipynb) to explore the projects.
